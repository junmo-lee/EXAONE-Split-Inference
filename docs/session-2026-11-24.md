# EXAONE 4.5 33B 실험 세션 기록

2026년 11월 24일 이 작업 세션에서 수행한 요청, 결정, 실험 결과와
재현 방법을 정리했다. 실험에는 동일한 Vast.ai 인스턴스의 RTX 4090
(24,564 MiB)과 AMD EPYC 7K62를 사용했다. 모델 가중치는 공식
BF16 체크포인트이며 GPU 디코더 선형 계층은 bitsandbytes NF4로
적재했다. 입력은 공개 질문 또는 합성 로그였다.

## 세션에서 완료한 작업

1. 공식 체크포인트와 Transformers 5.20.0을 확인했다. 별도 LM Head
   가중치를 적재하고, 각 샤드가 로컬 레이어 번호로 KV 캐시를 갱신하도록
   수정했다. TCP로 BF16 임베딩 또는 hidden state를 손실 없이 전달했다.
2. 기존 CPU 4층 / GPU 60층 분할에서 RTT, 대역폭, CPU 레이어 수를
   바꾸며 36회 측정했다. 짧은 입력에서 1 ms TCP 분할은 6.07토큰/s,
   GPU-only는 13.39토큰/s였다. [기본 보고서](../REPORT.md)
3. 같은 모델에 4,096토큰 합성 입력을 적용했다. CPU 4층 분할의 TTFT는
   158.72초였으며 CPU 구간이 156.54초를 차지했다. 초기 8스레드 시도는
   180초 서버 대기 제한을 넘겼다. CPU 스레드 24개와 서버 대기 제한
   600초로 재실행했다. [4층 장문 보고서](../results/long-prompt-4096.md)
4. `--split 0`을 추가했다. CPU는 채팅 템플릿, 토큰화, 임베딩 조회와
   최종 텍스트 디코딩을 맡는다. GPU는 64층, KV 캐시, 최종 norm·LM Head,
   greedy 토큰 선택을 처리해 토큰 ID를 반환한다.
   [임베딩 분할 분석](embedding-only-analysis.md)
5. 프레임 추적을 추가하고 같은 4,096토큰 입력으로 TCP 세션을 다시
   실행했다. GPU 답변은 `The access color is amber.`였다.
   [프레임 추적 JSONL](../results/embedding-only-tcp-trace.jsonl) ·
   [동일 실행의 생성 결과](../results/embedding-only-trace-generation.json)

## 4,096토큰 비교

동일 입력에 구성을 각각 3회 실행했다. 1 ms·10 Gbps는 루프백 TCP
왕복에 지연을 더해 모사했다. 임베딩 분할과 같은 회차에서 실행한 공식
GPU-only 경로를 아래 기준선으로 사용했다.

| 구성 | TTFT | 디코드 | GPU 사용률 평균 / 최대 | 장치 VRAM 표본 최대 |
|---|---:|---:|---:|---:|
| 공식 GPU-only NF4 | 2.090초 | 12.50토큰/s | 90.9% / 100% | 21,614 MiB |
| CPU 임베딩 / GPU 64층 TCP | 2.315초 | 12.10토큰/s | 82.1% / 100% | 20,241 MiB |

임베딩 분할의 CPU 임베딩·토큰 처리 시간은 계측된 전체 생성 시간의
0.57%였다. CPU 코어 사용률은 미계측이다. 애플리케이션의 전체 평균
송신량은 약 120 Mbps로 명목 대역폭의 1.20%에 해당한다. 이 값은 물리
NIC 점유율 측정과 구별된다. 프리필은 약 40 MiB를 한 번에 송신했고,
CPU 연산은 6.5 ms, 루프백 TCP·프레임 처리 잔여 시간은 183 ms,
가산한 RTT·대역폭 지연은 34.65 ms였다.

## TCP 추적과 재현

추적 JSONL에 초기화 2개, 프리필 2개, 디코드 12개의 애플리케이션
프레임을 기록했다. 요청·응답의 프레임 크기를 생성 결과의 송수신 합계와
대조했다.

| 단계 | CPU → GPU | GPU → CPU |
|---|---:|---:|
| 프리필 1회 | 41,943,120 B | 223 B |
| 디코드 6회 | 10,320 B/토큰 | 223~225 B/토큰 |

프리필 왕복 구간의 클라이언트 `TCP_INFO` 증분은 송신 데이터
세그먼트 681개, 수신 데이터 세그먼트 1개, 재전송 1회였다. 루프백
커널 카운터는 오프로딩과 ACK 동작에 영향을 받는다. 컨테이너에서
원시 소켓이 거부되어 개별 TCP 패킷 헤더 및 PCAP을 수집할 수 없었다.
JSONL에는 텐서 내용과 생성 토큰 ID가 들어 있지 않다.

터미널 A에서 GPU 서버를 실행한다.

```bash
OMP_NUM_THREADS=8 python -m exaone_split.cli server \
  --dir /root/exaone-model --split 0 --host 127.0.0.1 --port 9876
```

서버가 준비되면 터미널 B에서 공개 합성 입력으로 추적한다.
`--trace-jsonl`에는 새 파일 경로를 지정한다.

```bash
prompt=$(python -c 'import json; print(json.load(open("results/long-prompt-4096-embedding-only.json"))["prompt"])')
OMP_NUM_THREADS=8 MKL_NUM_THREADS=8 python -m exaone_split.cli client \
  --dir /root/exaone-model --split 0 --host 127.0.0.1 --port 9876 \
  --rtt-ms 1 --bandwidth-mbps 10000 --max-tokens 12 --prompt "$prompt" \
  --trace-jsonl results/tcp-trace-rerun.jsonl
```

파일, 로컬 캐시와 서비스 시작 로그는 GitHub 공개 자료에서 제외했다.
